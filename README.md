# 📚 Лабораторная работа №1: Каркас приложения и базовый REST API

## Цель работы
Получение практических навыков создания веб-приложения на FastAPI, настройки маршрутизации, использования Pydantic-моделей и реализации базового CRUD-интерфейса без использования базы данных (хранение в оперативной памяти) для предметной области «Библиотека».

## Выполненные задачи
- [x] Инициализирован проект со структурой, рекомендованной методическими указаниями (`app/api/v1`, `app/schemas`, `app/services`).
- [x] Реализована схема данных **Book** (Книга) с использованием Pydantic v2 (`BookCreate`, `BookRead`) для валидации входных и выходных данных.
- [x] Настроены обязательные эндпоинты версии `v1`:
  - `GET /api/v1/books` — получение списка всех книг.
  - `GET /api/v1/books/{book_id}` — получение книги по ID.
  - `POST /api/v1/books` — создание новой книги (статус `201 Created`).
  - `PUT /api/v1/books/{book_id}` — обновление данных книги.
  - `DELETE /api/v1/books/{book_id}` — удаление книги (статус `204 No Content`).
- [x] Реализовано временное хранилище данных в оперативной памяти (список `_books_db`) согласно заданию первой лабы.
- [x] Обеспечена корректная обработка ошибок: `404 Not Found` при отсутствии объекта, `422 Validation Error` при невалидных данных.
- [x] Настроена автоматическая интерактивная документация OpenAPI (Swagger UI).
- [x] Протестированы все CRUD-операции через PowerShell (`Invoke-WebRequest`).
